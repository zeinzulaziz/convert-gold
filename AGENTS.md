# AGENTS.md - Convert Gold

## Anti-Slop Rules (minimal)
- Jangan tambahin buzzword: "AI Powered", "Next Gen", "Seamless", dll
- Jangan bikin fake stats/testimonial/avatar/logo tanpa minta
- CTA harus spesifik (bukan "Get Started"/"Learn More")
- Hindari template berulang: "How it works 3 steps", pricing 3 kolom, dll
- Prioritas fungsional: tombol/link harus ada tujuan nyata
- Mobile-first: no horizontal scroll, tap target >=44px
- Kontras teks cukup (hindari grey text on grey)
- Jangan patch file via script (edit source langsung)

## Impeccable Rules (minimal)
- Setiap perubahan UI harus ada alasan singkat ("why")
- Pake spacing/typography konsisten
- Jangan clone UI populer tanpa diminta
- Pertahankan identitas project ini (dark theme + gold accent)
- Cek console/build + klik elemen penting sebelum bilang "done"

## Project Notes
- Static site (GitHub Pages). Hanya HTML/CSS/JS vanilla.
- Data live: gold price (xaus/mintedmetal), kurs USD/IDR (Frankfurter)
- Data Indonesia (Antam/UBS/Pegadaian) diambil via proxy CORS dari hargaemas.com
